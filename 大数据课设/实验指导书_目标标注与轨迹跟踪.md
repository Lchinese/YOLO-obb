无人机交叉口交通目标标注与轨迹跟踪实验指导书

# 一、实验目的

通过对无人机俯视交叉口视频帧开展目标标注修正、轨迹跟踪校正以及跟踪复现实验，掌握面向交通场景的数据清洗、时序标注规范与视频推理验证流程。学生应理解单帧检测准确性与跨帧身份一致性同等重要，能够独立完成目标框修正、类别核验、Track
ID
校正、漏标补全、连续轨迹检查，以及利用已训练模型完成视频预测、结果可视化和轨迹导出。

本实验完成后，学生应具备以下能力：一是能够对行人、非机动车等运动目标进行规范标注；二是能够在连续帧中维持同一目标的
ID 一致；三是能够发现并修正跳帧、换
ID、漏检和错误关联等常见问题；四是能够调用已有检测与跟踪模型，对视频完成预测跟踪、结果可视化以及跟踪框与轨迹坐标序列导出。

# 三、实验数据说明

实验数据为无人机拍摄的城市交叉口俯视视频帧序列，总规模约3600帧。场景中包含机动车、行人、电动自行车等多类交通参与者，且存在遮挡、密集交互、转向、启停与交叉通过等复杂现象。除帧级标注修正任务外，教师还提供已训练好的检测与跟踪模型及示例脚本，用于完成视频预测跟踪复现实验。

每位学生负责约40张图像的修正工作。修正对象不仅包括单帧中的目标框与类别，还包括跨帧的同一目标身份
ID
和运动轨迹连续性。在完成数据修正后，学生还需使用已有模型对指定视频进行推理，并导出跟踪结果文件。

# 四、任务具体要求

（一）目标标注部分

> •
> 检查每帧中是否存在漏标、错标、重复标注、目标框位置偏移、目标框角度不合理等问题。
>
> •
> 对行人、电动自行车等目标进行准确区分，标注框应尽量贴合目标实际轮廓，避免明显过大、过小或偏移。
>
> • 若某帧中存在应标未标的目标，应补充对应检测框，并填写正确类别与 Track
> ID。
>
> •
> 每位学生需完成分配到的40张图像修正，该部分数据作为各自模型的训练集和测试集基础。

（二）ID连续性校正部分

> •
> 轨迹跟踪包含"目标检测"和"目标跟踪"两层含义：前者要求每名行人、每辆电动自行车都被准确识别；后者要求同一运动对象在
> 40 张图片中的 ID 始终一致。
>
> •
> 本实验不是简单的类型分类，而是面向具体运动对象的实例级识别与跟踪。同一辆车在连续帧中必须保持同一个
> ID；同一名行人或同一辆电动自行车也必须保持 ID 一致。
>
> • 若某目标在后续帧中被错误分配为新的
> ID，须从发生错误的那一帧开始回溯校正，统一为正确 ID。
>
> •
> 轨迹应尽量连续，不允许无故跳帧。若目标在相邻帧仍可见但中间某帧漏标，应及时人工补框并保持
> ID 延续；若因严重遮挡短暂不可见，应结合前后帧判断是否应继续使用原 ID。
>
> • 对交叉、遮挡、并行行驶、会车等易混淆场景，要重点检查是否出现 ID
> 交换、轨迹断裂或错误关联。

（三）跟踪复现实验

> •
> 本实验的跟踪复现实验不要求学生重新训练模型，而是直接调用教师已提供或已训练好的检测模型、跟踪模型和示例脚本，对指定视频完成一次完整的视频预测跟踪流程。有能力的同学，也鼓励开发新模型。
>
> •
> 学生需能够正确配置运行环境，理解模型权重路径、视频路径、输出路径等基本参数含义，并成功运行命令行或
> Python 脚本完成推理。
>
> • 复现实验至少应产出以下结果：① 带检测框、Track ID
> 和类别信息的可视化视频；② 逐帧跟踪框坐标文件；③ 按 Track ID
> 组织的轨迹中心点坐标序列；④ 轨迹路线图或轨迹叠加可视化结果。

（四）模型训练实验

> •
> 学生需在完成40张图像标注修正与ID校正后，使用修正后的数据构建训练集与验证集（建议8:2划分）。
>
> •
> 使用YOLO_OBB模型进行训练，需完成数据配置文件（.yaml）编写，包括类别数、类别名称及路径配置。
>
> •
> 能够正确调用训练脚本（train.py）并完成模型训练，生成best.pt权重文件。
>
> •
> 学生需理解基本训练参数（epochs、batch等）的含义，并可根据设备进行调整。
>
> • 训练完成后，应使用训练得到的模型进行简单推理验证模型有效性。

# 五、判定标准与质量规范

• 检测准确：每个可见运动目标均应被正确框选，类别无明显错误。

•
边框合理：旋转框方向与目标朝向基本一致，框体尽量贴合目标，不截断、不漂移。

• 身份一致：同一目标在连续帧中的 Track ID 保持一致，不随意变更。

• 轨迹连续：目标在可见区间内不应出现无故漏帧、断裂或跳号。

•
文件一致：图像文件与对应标签文件同名，保存格式正确，标签内容可正常读取。

•
运行正确：给定模型和视频后，程序能够正常完成推理，不因路径、依赖或参数配置错误而中断。

•
输出完整：应生成可视化视频、逐帧跟踪框坐标文件和轨迹路线结果；输出文件命名清晰、路径可追溯、内容可正常读取。

•
结果可核验：导出的坐标序列应与视频中的跟踪框位置基本一致，轨迹路线与目标运动趋势相符，便于后续分析与复查。

• 模型训练有效：能够成功完成训练并生成模型权重文件。

• 推理结果合理：检测框位置与实际目标基本一致。

• 配置正确：数据路径、类别数量及参数设置无错误。
